# Template · Product Spec 契约模版

这是 `Stop Before Code (SBC)` 在 Phase 4 生成的标准化契约文件 `.product-spec.md` 结构。

---

```markdown
# Product Spec: [产品或功能名称]

> **Appetite**: [Small Batch (≤30m) / Medium Batch (≤半天) / Large Batch]  
> **Form**: [CLI / Browser Extension / Single Page Web / Micro-Service]  
> **Status**: [PENDING_SIGNATURE / APPROVED]  
> **Source of Truth**: 本文件为唯一实现契约。未在本文中记录的特性一律禁止编写。

---

## 1. 核心价值与 JTBD (Jobs to be Done)
- **场景触发 (When)**: [用户在什么特定时刻或遇到什么状况]
- **核心动作 (Action)**: [通过什么最简单的方式触发/使用该功能]
- **交付价值 (Outcome)**: [解决什么痛点，取代过去何种繁琐操作]

---

## 2. 形态与交互流 (The Shape)

### 界面与视觉草图 (ASCII Fat-Marker Wireframe)
```text
+-----------------------------------------------------------+
| [产品/窗口标题]                                  [_][X]   |
+-----------------------------------------------------------+
|  [输入/核心操作区]                                         |
|  > 输入提示占位符...                    [执行/主操作按钮]   |
+-----------------------------------------------------------+
|  [核心状态/数据展示区]                                     |
|  * 状态展示 / 列表项 1                                    |
|  * 状态展示 / 列表项 2                                    |
+-----------------------------------------------------------+
| [状态栏: 简短人话反馈]                                     |
+-----------------------------------------------------------+
```

### 核心用户旅程 (Happy Path)
1. **触发**: 用户 [操作动作] ->
2. **处理**: 系统以 [某种机制] 执行 ->
3. **反馈**: 界面/终端即时呈现 [确切结果]。

---

## 3. 绝不碰的禁区 (Anti-Scope / No-Gos)
> 强制减法：以下特性在本期绝对不碰，避免复杂度膨胀。

- ❌ **明确不做的功能 1**: [例如：本期不做跨设备云端同步]
- ❌ **明确不做的功能 2**: [例如：本期不做多用户与登录体系]
- ❌ **绕开的兔子洞**: [例如：不引入臃肿的 ORM，直接采用极简 SQLite 或本地 JSON 文件]

---

## 4. 冷启动与容错契约 (Edge Contract)
- **冷启动与空状态 (Empty State)**: [首次使用无任何数据时，展示什么人话引导文案]
- **输入异常处理**: [参数错误/格式非法时，如何给出具体、友好的修复建议]
- **破坏性操作保护**: [是否涉及覆盖/删除？如何进行轻量确认防护]

---

## 5. 完成定义 (Definition of Done)
> 只有通过以下客观命令或步骤的验证，本次交付才算合格。

- [ ] **自动化验证命令**:
  ```bash
  [具体的命令，例如 npm test 或 ./cli.sh --test]
  ```
  *预期输出*: `[确切的成功输出或断言返回]`

- [ ] **人话验收操作**:
  1. 运行 `[启动命令]`
  2. 执行 `[操作步骤]`
  3. 观察到 `[确切效果]`
```
